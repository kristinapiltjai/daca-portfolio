## Sellel nädalal 

seadistasin meie tiimile GitHubi repo ning kutsusin sinna kõik liikmed collaboratori'teks.
Lisaks commit'isin charter.md GitHubi.
Tegin meie tiimile Google Chati eraldi vestlusakna.

## Õppisin 

programme seadistama: supabase, GitHub konto + Git ning VS Code. Ja õppisin veidi kõiki neid programme ka kasutama kui oli seadistus ära tehtud.

## AI kasutamine

küsisin abi, mis võiks olla meeskonna eesmärk vastavalt ülesandele. 
Lisaks küsisin: Kuidas kirjutada hea README.md fail meeskonna projekti jaoks? Mis peaks seal kindlasti olema? 
Samuti ma ei saanud päris täpselt aru, kas inimesel on ikka admin õigused seega küsisin AI-lt üle: Kuidas ma näen githubis, kas inimesel on admin õigused kui ta on collaboratorina lisatud? 
Ja lisaks küsisin AI-lt mis on markdown formaa ja lasin tal teksti markdown formaadis teha.
