Sellel nädalal õppisin Supabases SQL koode kasutama - SELECT, FROM, ORDER BY, LIMIT, WHERE, DISTINCT JA COUNT.
Lisaks pusisin ma tükk aega, et enda õiget kausta VS Codest Githubi saada ja see võttis ikka 2-3 tundi aega, aga sain tehtud.
Arvasin, et faile tuleb täita ja teha Githubis, aga tegelikult peab VS Codes ja siis VS Codest saadad Githubi.
Tänu sellele, et pusisin sellega nii tükk aega sain vähemalt asja selgeks ja pilt on palju selgem juba.

AI abi kasutasin väga palju just notebook LM oma, et enda VS Code ja Github omavahel ära ühendada. Terve aja kasutasin põhimõtteliselt seda ja sellest oli väga palju abi.
SQL koodide jaoks kasutasin Notebook LM peamiselt kui pidin ise käsitsi päringuid kirjutama. Kõigepealt proovisin ise, aga siis iga kord olid tabelite nimed valed ning seega läksin AI-lt üle kontrollima ja tegelt päring oli justkui õige, aga nimed olid valed.
